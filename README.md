# CP-C&CG

Code for the paper
"Exact scenario-pruned column-and-constraint generation for two-stage adaptive robust optimization"
(Chen and Wu, ResearchGate).

SP-C&CG is an exact acceleration of standard C&CG: it prunes historical scenarios online
by their projections onto cached dual directions, with a strict lower-bound rule preserving convergence.
